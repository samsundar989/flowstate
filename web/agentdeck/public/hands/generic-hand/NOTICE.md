# Hand models

`left.glb` and `right.glb` are unmodified copies of
`dist/profiles/generic-hand/{left,right}.glb` from the npm package
`@webxr-input-profiles/assets@1.0.20`
(https://github.com/immersive-web/webxr-input-profiles, `packages/assets`).
They are the same bytes the SDK's default public-CDN URL resolves to.
