# Sound set

11 short UI cues shared by the Unity and WebXR builds. Every file here was **generated by
`gen_sounds.py`** with additive sine synthesis (Python stdlib only). There are no
third-party samples, no recordings and no licence constraints; the files are dedicated
CC0 by this project.

Regenerate (deterministic, byte-identical output; fixed seed 56):

    python -I assets/audio/gen_sounds.py

Format: 48 kHz, 16-bit PCM, mono WAV. Every cue is loudness-matched to **-18.0 dBFS RMS**
(measured over the whole file) and has 5 ms fade-in/fade-out so nothing clicks. All
peaks are at or below -3.9 dBFS. Total size 313,444 bytes.

| file | ms | peak dBFS | RMS dBFS | trigger (schema event / UI action) | design intent |
|---|---|---|---|---|---|
| `hover.wav` | 60 | -7.3 | -18.0 | finger enters the 3 cm hover zone of a poke button; ray hovers a node | faint high blip (C7), the lightest cue; play at low gain (see note) |

## Notes for integrators

- **Per-agent pitch** (design.md §5): agent A +0, B +3, C +7 semitones. Apply it at
  runtime (Unity `AudioSource.pitch = 2^(st/12)`; Web Audio `playbackRate`), do not
  bake extra files.
- **Mixing:** files are matched at the same RMS so the engine controls relative level.
  Suggested starting gains: `hover` -12 dB, `press`/`tick` -6 dB, everything else 0 dB,
  bed loop -30 dB (§5).
- **Names vs design.md §5:** this set follows the task-#56 list. §5's `pickup` → `assign`,
  `return` → `snap-back`. §5's `wake` and `drop-thunk` are not separate files (`tick` and
  `press` cover them). §5 says `payoff` 1.5 s; this task fixed it at 1.2 s.
- `preview.html` in this folder plays each cue on click (shift-click also plays the +3 and
  +7 semitone agent variants). Open it from disk or any static server.
